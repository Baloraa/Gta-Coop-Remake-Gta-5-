AddonPed+  -  standalone addon ped mod
======================================

Completely independent of the GTACoop launcher and server. It does not break
your game or your existing mods: it only adds its own DLC folder, its own
script files and a single dlclist entry (gtacoop_peds). Uninstalling removes
them again. It can be used alongside AddonPeds (ap_m.xml) and other ped mods.

Folder contents
---------------
  AddonPedPlus.exe          Desktop tool (add peds, build OIV, install / remove)
  payload\AddonPedPlus.dll  In-game ped selector script
  AddonPedPlus.ini          In-game menu key setting (goes to scripts on install)
  AddonPedPlus.oiv          Ready-made OpenIV package (if present; the tool builds one)
  OKUBENI.txt               This file

Requirements
------------
  * GTA V (Legacy or Enhanced)
  * ScriptHookV               (matching your game build)
  * ScriptHookVDotNet 3       (installed into the scripts folder)
  * A mods folder created with OpenIV: mods\update\update.rpf
  * .NET 8 Desktop Runtime (x64)  ->  https://dotnet.microsoft.com/download/dotnet/8.0
    (The tool is shipped small, so this runtime is required. A self-contained
     ~160 MB build can be produced with the repository's `-SelfContained` switch.)

Install - option 1 (with the tool)
----------------------------------
  1. Prepare your ped files (.yft / .ydd / .ytd / .ymt).
  2. Open AddonPedPlus.exe.
  3. Use "Add Peds..." or "Add Streamed Folder..." to add the files.
  4. Untick the peds you do not want.
  5. "Install to Game..." -> choose your GTA V folder (the one with GTA5.exe or
     GTA5_Enhanced.exe).
  6. Press the menu key in game (default: F10).

Install - option 2 (with OpenIV)
--------------------------------
  1. Build AddonPedPlus.oiv with "Build OIV..." in the tool (or use the one
     included here).
  2. OpenIV -> Tools -> Package Installer -> select the .oiv file -> Install.
  3. To remove it, uninstall the same package in OpenIV.

In-game menu (English by default)
---------------------------------
  F10 (configurable)   open / close the menu
  Up / Down            move the selection
  Enter                apply the selected ped
  Default entry        go back to the normal character
  Back entry           close the menu
  Esc                  close the menu (does not change the ped)

The desktop tool's interface is English by default; switch it to Turkish with
the Language selector ("Dil") in the button bar.

Changing the menu key
---------------------
  Open  scripts\AddonPedPlus.ini  in your game folder:

    [AddonPedPlus]
    MenuKey=F10

  Replace MenuKey with the key you want: F1..F12, M, INSERT, HOME and so on
  (System.Windows.Forms.Keys names). Restart the game afterwards.

Removing the mod
----------------
  * From the tool: "Uninstall" (removes only the files it installed)
  * From OpenIV: uninstall the package
  * Manually: delete  mods\update\x64\dlcpacks\gtacoop_peds, delete
    AddonPedPlus.dll / AddonPedPlus.ini / GTACoop-peds.txt from scripts, and
    remove the  <Item>dlcpacks:/gtacoop_peds/</Item>  line from dlclist.xml
    inside mods\update\update.rpf.

Troubleshooting
---------------
  * The menu does not open: check  scripts\AddonPedPlus.log  (and
    GTACoop-pedselector.log); make sure ScriptHookV and ScriptHookVDotNet are
    installed and match your game build.
  * "Ped not loaded" warning: the DLC is not installed or the dlclist entry is
    missing.
  * A ped is invisible: its .yft/.ydd/.ytd files may be missing; read the
    warnings in the tool's log.
  * If F10 is used by another mod, pick another key in the ini file.
