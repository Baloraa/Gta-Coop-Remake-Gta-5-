==========================================================
 GTACoop Remake - Joining a Server (v2.3.5)
==========================================================

There are two ways to join:

  1) SHORT CODE (for example Gel.com)  ->  RECOMMENDED
     The launcher looks the server details up over the internet.
     It also opens an automatic relay, so no port forwarding or
     Radmin VPN is required.

  2) LONG CODE (GTC1...)
     The code carries the connection details itself; no internet
     lookup is required. If it was created while the server was
     running, it also carries the automatic relay details. If a
     short code is configured in "My Server", the long code carries
     it too; the launcher then refreshes the current relay ports
     when your friend connects, so the same long code keeps working
     after a server restart.

Both are pasted into "Join with Code..." on the "Servers" tab.

------------------------------------------------------------------
SERVER OWNER - SHORT CODE (recommended)
------------------------------------------------------------------
1) In the "My Server" tab, check the server name, game port
   (default 4499) and sync port (default 4599). You may also set
   a password and sync token (optional).

2) Enter a code such as Gel.com in the "Short code" field and
   click Save.
   - 3-64 characters: letters, digits, dot, dash, underscore.
   - Upper/lower case does not matter.
   - Leave it empty to turn the short code off.
   - Codes starting with "GTC1." cannot be used as short codes.

3) Click "Start Server". Under the short code field you should
   see "Short code online: Gel.com" and "Automatic relay:
   <server> ...". The relay is usually ready in 1-2 seconds.
   If "Relay server" is empty, bore.pub is used; you can enter
   your own bore-compatible server as "host:port". If the router
   supports UPnP, the game (UDP) and sync (TCP) ports are also
   mapped automatically; otherwise the relay keeps working.
   The launcher publishes the code encrypted via ntfy.sh and
   refreshes it every 60 seconds; it goes offline when the
   server stops.

4) Send ONLY the short code to your friend (WhatsApp/Discord).

5) When your friend enters the code, the launcher first tries the
   automatic relay; if the relay cannot be established, it falls
   back to same-network/Radmin/port-forwarding addresses. The
   server and your friend's launcher MUST stay open while playing.

Note: the short code also carries the server password and sync
token (encrypted); only give it to people you trust. Relay traffic
goes through bore.pub on a random public port. The relay can be a
little slower than a direct connection. If you are on the same
Wi-Fi/hotspot or Radmin VPN, choose "Direct" mode in the join
window.

------------------------------------------------------------------
SERVER OWNER - LONG CODE (GTC1...)
------------------------------------------------------------------
1) In the "My Server" tab, check the server name and ports.

2) Click "Create Join Code...".

3) Pick the address your friend will use from the
   "Server address" list:
   - Same home/network: 192.168.x.x (Wi-Fi/Ethernet)
   - Using Radmin VPN:  26.x.x.x
   - Port forwarding + public IP: type the public IP manually
   You can always type an address manually.

4) Click "Copy" and send the code to your friend
   (WhatsApp, Discord, etc.).

5) Click "Start Server". When your friend joins with the code,
   server mods download automatically.

Note: the long code carries the connection details itself and
can be created while the server is stopped. If you create it
while the server is running, the relay endpoints are included
too. If a short code is configured, it is embedded in the long
code and the relay information is refreshed through it when your
friend connects, so the same long code still works after a server
restart. Without a short code, the relay information in the long
code is valid for one session; create a new long code after
restarting the server. It may contain the password/token; only
give it to people you trust.

------------------------------------------------------------------
FRIEND (JOINING)
------------------------------------------------------------------
1) Open the launcher and go to the "Servers" tab.

2) Click "Join with Code...". If the code is in your clipboard,
   the window fills it in automatically; otherwise paste it.

3) If you enter a short code (Gel.com), the launcher fetches the
   server details from the internet and tries the automatic relay
   first. The server and your launcher must be running. If you
   enter a long code (GTC1...), the details are read from the code
   itself; if the code contains a short code, the relay information
   is refreshed when connecting. Without a short code, relay ports
   from an earlier server session may be stale after a restart;
   ask the server owner for a new code.

4) When the details appear, click "Add and Connect". The server
   is added to the list, mods download, and the game starts.

5) DO NOT CLOSE THE LAUNCHER while playing. The relay carries the
   game traffic through the launcher; closing it disconnects you.
   You can close the launcher after exiting the game; server mods
   are removed automatically.

6) On first join, open chat with T and type:
      /register password
   Later sessions:
      /login password
   Player list: Z. GTA Coop menu: F9. Voice chat: N (change it in F9 > Settings).

You can still play without a code: "Add Server..." and manual
IP/port entry work as before (direct connectivity or Radmin VPN
is required for that path).

------------------------------------------------------------------
WHERE ARE MODS STORED? / RE-DOWNLOAD
------------------------------------------------------------------
Downloaded server mods are kept in the program folder, in a
separate folder for each server:

  <GTACoop Remake folder>\Servers\<server name>__<server id>\

- Every server has its own folder; servers never mix.
- DLC packs are not copied into the game folder; they are
  referenced from this folder via an NTFS junction.
- Script/ASI files are installed temporarily while playing and
  removed automatically on exit. Your own mods are untouched.
- Files that were already downloaded are skipped on later joins.
- If a download is broken or incomplete: select the server in
  the "Servers" tab and click "Re-download...", then confirm.
  Only that server's downloaded files are deleted and fetched
  again (they are not installed into the game).
- This is blocked while that server's mods are installed in the
  game; click "End Session" first.
- To open the folder: "My Server" -> "Open Server Folders".
- The server.json file inside identifies the server.

This is similar to FiveM: content lives next to the program,
per server, and the original game files are not modified.

------------------------------------------------------------------
FAQ
------------------------------------------------------------------
- Short code not found: is the server running, did you type the
  code correctly, and is your internet working? A short code is
  published only after the server starts. You can also try the
  long GTC1 code.
- Short code found but no connection: make sure both you and the
  server owner use v2.3.5 or newer. The server should show
  "Automatic relay: <server> ...". Wait a few seconds and click
  "Search Again".
- Relay not working: bore.pub (or the custom relay chosen by the
  server owner) may be unreachable. Use Radmin VPN
  (free) or forward 4499 UDP + 4599 TCP for a direct connection,
  or try a current long GTC1 code created while the server was
  running.
- Long code does not work: make sure you copied all of it.
  Line breaks are fine; the launcher strips whitespace. If the
  server was restarted and the code has no short code, its relay
  ports may be stale; ask for a new long code created while the
  server is running. Long codes with a short code refresh the
  relay information automatically.
- Same network: a local IP is enough. For internet play, the
  short code plus automatic relay is the easiest path.
- You can create a long code while the server is stopped; your
  friend will connect once you start it.
- Do not close the launcher while playing; the relay connection
  would drop.
