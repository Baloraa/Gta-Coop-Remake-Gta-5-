==========================================================
 GTACoop Remake - Friend Edition (English, v2.2.2)
==========================================================

This is a friend-to-friend co-op tool for GTA V (Story Mode).
The server owner adds mods; when you connect, they are downloaded
and installed automatically, then removed when you exit the game.

------------------------------------------------------------------
INSTALLATION
------------------------------------------------------------------
1) Extract this folder somewhere on your PC
   (for example C:\GTACoop-Remake).

2) Run GTACoop.Launcher.exe.
   - If Windows shows an "unknown publisher" warning:
     click "More info" -> "Run anyway" (the app is unsigned,
     this is normal).
   - If you get "You must install .NET", install the
     .NET 8 Desktop Runtime:
     https://dotnet.microsoft.com/en-us/download/dotnet/8.0

3) In the launcher, open the "Game" tab:
   - Click "Browse..." and select your GTA V folder
     (the folder that contains GTA5.exe).
   - Click "Install / Update Client".

   REQUIRED:
   - Original GTA V (Steam/Epic/Rockstar, Story Mode)
   - Microsoft Visual C++ runtime (already present on most PCs)

   Install ScriptHookV and ScriptHookVDotNet from the
   "Components" tab by choosing a version. OpenIV.asi is bundled;
   install it with "Components > OpenIV.asi (bundled)".
   NativeTrainer.asi is never installed; your own scripts and mods
   are preserved. ScriptHookV/SHVDN files are not bundled (their
   licenses do not allow redistribution); they are downloaded only
   when you choose them.

4) Open the "Servers" tab:
   - EASIEST: ask the server owner for the SHORT CODE
     (for example Gel.com). Click "Join with Code...", type the
     short code and click "Add and Connect". The launcher looks
     the server up over the internet and uses the automatic relay
     if direct addresses do not work. No port forwarding or
     Radmin VPN is required. The server must be running and you
     need an internet connection.
   - The owner may instead send a long GTC1 code. That code
     carries the address/ports/password by itself and needs no
     internet lookup (no relay; direct connectivity is required).
   - Alternative: click "Add Server..." and enter the address and
     ports given by the server owner (game port 4499 UDP,
     sync port 4599 TCP).
   - Click "Connect & Play". Server mods download automatically
     and the game starts. Details: JOIN-WITH-CODE-EN.txt

5) In game:
   - F9  : GTA Coop menu
   - T   : chat
   - Z   : player list
   - On first join, type in chat:   /register password
     (later sessions:               /login password)

------------------------------------------------------------------
IMPORTANT NOTES
------------------------------------------------------------------
- This tool does not touch GTA Online; it works in Story Mode only.
- YOUR OWN mods are never touched. If a server mod already exists
  on your PC, it is skipped: not downloaded, not overwritten.
- Server mods are installed only while you play; they are removed
  automatically when you exit the game.
- Downloaded server files are stored per server in the program
  folder: Servers\<server name>__<server id>\
  (open it via "My Server" -> "Open Server Folders").
- Files that were already downloaded are skipped on later joins.
  If a download looks broken or incomplete, select the server in
  the "Servers" tab and click "Re-download..." to delete and
  download that server's files again (they are not installed
  into the game). This is blocked while that server's mods are
  installed in the game; use "End Session" first.
- Your game files are not modified. The "Components" tab updates
  only the component files you choose; changed files are backed up
  under mods\GTACoop\backups\components first. Your own mods and
  existing ScriptHook settings are preserved.
- If you use a short code/automatic relay, keep GTACoop.Launcher
  open while playing; the relay carries game traffic through the
  launcher. You can close it after exiting the game.
- Hosting your own server additionally requires .NET 10.
