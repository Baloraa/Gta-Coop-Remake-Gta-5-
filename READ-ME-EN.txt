==========================================================
 GTACoop Remake - Friend Edition (English, v2.14.0)
==========================================================

This is a friend-to-friend co-op tool for GTA V (Story Mode).
The server owner adds mods; when you connect, they are downloaded
and installed automatically, then removed when you exit the game.

------------------------------------------------------------------
NEW IN 2.14.0
------------------------------------------------------------------
- The launcher is a dark WPF shell now: collapsible side menu,
  consistent dark drop-downs, buttons, lists and grid lines, and
  the window always fits your screen work area.
- DLC packs mount through ownership-verified junctions; mounting,
  unmounting, target checks and backup rollback are stricter.
  Uninstalling no longer deletes cache files; cache cleanup is a
  separate action.
- OIV packages are routed into OpenIV's mods layer. There is no
  real-time virtualisation for OIV, ASI or scripts.
- 14 smoke tests cover path safety, manifest validation, DLC
  junction mount/unmount and symlink rejection.

Optional standalone mod: AddonPed+ (own add-on ped pack and ped
selector, works without the launcher or a server). See
ADDONPEDPLUS-OKUBENI.txt in the AddonPed+ ZIP.

------------------------------------------------------------------
INSTALL
------------------------------------------------------------------
1) Extract this folder somewhere on your PC
   (for example C:\GTACoop-Remake).

2) Run GTACoop.Launcher.exe.
   - If Windows shows an "unknown publisher" warning, click
     "More info" -> "Run anyway" (the app is not code-signed).
   - If you see "You must install .NET", install the .NET 8
     Desktop Runtime:
     https://dotnet.microsoft.com/download/dotnet/8.0

3) In the launcher, open the "Game" tab:
   - Pick your GTA V folder with "Browse..."
     (the folder that contains GTA5.exe).
   - Press "Install / Update Client".
   - The default launch executable is PlayGTAV.exe. If you start
     GTA5.exe directly, choose it with "Launch Path...".

   REQUIRED:
   - A legitimate GTA V (Steam/Epic/Rockstar, story mode)
   - Microsoft Visual C++ runtime (already present on most PCs)

   ScriptHookV and ScriptHookVDotNet can be installed from the
   "Components" tab by choosing a version. OpenIV.asi ships with
   the package; install it with "Components > OpenIV.asi (bundled)".
   NativeTrainer.asi is not installed; your own scripts and mods
   are kept. ScriptHookV/SHVDN files are not bundled for licensing
   reasons; they are only downloaded when you ask for them.

4) "Servers" tab:
   - EASIEST: type the SHORT CODE the host sent you
     (for example Gel.com) into "Join with Code..." and press
     "Add and Connect". The launcher looks the server details up
     over the internet and tries the automatic relay first; if the
     relay cannot be set up it falls back to a reachable direct
     address. No port forwarding or Radmin VPN is needed. The
     server must be online and your internet must work. The host
     can pick a custom relay under "My Server > Relay server"; the
     connection then does not fall back to bore.pub. If the router
     supports UPnP the game/sync ports are opened automatically;
     otherwise the relay stays in use.
   - If the host sent a long GTC1 code, paste it into the same box;
     the long code carries the details itself. If it was created
     while the server was online it also carries the relay info.
     Relay ports are refreshed automatically when the code has a
     short code. If there is no short code and the server was
     restarted, ask for a new code.
   - Alternative: press "Add Server" and enter the address and
     ports the host gave you (game port 4499 UDP, sync 4599 TCP).
   - Press "Connect & Play". Server mods download automatically
     and the game starts. Details: JOIN-WITH-CODE-EN.txt
   - Alternative: use "Server Browser" to scan the GTACoOp master
     list, the LAN or a direct IP:port. Server name, player count,
     mode, password, ping and version (current/old) are shown.
     If there is no sync server, the game starts without mods.
   - The in-game F9 > Server Browser shows the same list; it works
     even if you start the game without the launcher.
   - Join only after the host is fully in the game; the GTACoOp
     session becomes active once the host is in.

   NOTE: if your mods\update\update.rpf is close to 3.9 GB or its
   structure is broken, DLC packs are skipped for safety. The
   launcher does not modify that file; script/ASI mods still
   install. Use the launcher's "Backups" section to repair.

   NOTE: on GTA V Enhanced, add-on DLC (vehicle/ped) packs cannot
   be installed. Enhanced archives are NG encrypted, so
   mods\update\update.rpf cannot be written; the launcher never
   copies or changes that file. Script and ASI mods install
   normally. Add-on DLC packs need classic (Legacy) GTA V or an
   unencrypted (OPEN) mods copy plus RageOpenV/OpenRPF. It works on
   FiveM because FiveM registers files in memory while the game
   runs; Story Mode has no such path.

   If downloads are slow or the connection drops, the launcher
   retries automatically and resumes where it stopped. Large files
   use split downloads (2 parallel connections above 4 MB, 4 above
   12 MB) and the relay is skipped when the server is on the same
   network. If problems persist, send
   %LOCALAPPDATA%\GTACoopRemake\logs\launcher-<date>.log to the host.

5) In game:
   - F9  : GTA Coop menu
   - F9 > Teleport to Player: jump to a player from the list. If
     that player is driving, you take the first free passenger seat;
     if the vehicle is full you teleport next to it.
   - T   : chat
   - Z   : player list
   - N   : voice chat (push-to-talk; change it in F9 > Settings)
   - First join, in chat:  /register password
     (later joins:        /login password)

------------------------------------------------------------------
IMPORTANT NOTES
------------------------------------------------------------------
- This tool never touches GTA Online; it only works in Story Mode.
- While you talk in voice chat a [MIC] marker appears next to your
  name. Change the push-to-talk key in F9 > Settings > Voice Chat
  Key.
- Story missions: F9 > Story Mission Co-op (host-led). The host
  starts the mission via Pause > Game > Replay Mission; friends
  help in the same world. Objectives and cutscenes belong to the
  host and no save file is written. You do not need the same save
  game.
- YOUR own mods are never touched. If a server mod already exists
  on your PC it is skipped: not downloaded, not overwritten.
- Server scripts install directly into scripts\; nested folders
  such as scripts\scripts\... are never created.
- Server mods are installed only while you play; they are removed
  automatically when you exit the game.
- If the host disables mods, nothing is downloaded or installed
  when you join, and previously installed server mods are removed.
- Downloaded mod files are kept per server in the program folder:
  Servers\<server name>__<server id>\ ("My Server" -> "Open Server
  Folders" shows them).
- Files downloaded before are not downloaded again. If a download
  is corrupt or incomplete, select the server in "Servers" and use
  "Re-download..."; that server's files are deleted and fetched
  again (not installed into the game). This does not run while
  mods are installed; use "End Session" first.
- While a large DLC downloads you see the size and speed on
  screen. If the connection drops the download resumes.
- Your game files are not modified. The "Components" tab only
  updates the component files you select; replaced files are first
  backed up under mods\GTACoop\backups\components. Your own mods
  and current ScriptHook settings are kept.
- If you use a short code or the automatic relay, keep
  GTACoop.Launcher open while playing; the relay carries the game
  traffic through the launcher. You can close the launcher once you
  quit the game.
- Hosting your own server additionally requires .NET 10.
